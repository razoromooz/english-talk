# English Talk — آموزش مکالمه انگلیسی 🇬🇧

وب‌اپلیکیشن موبایلی (PWA) آموزش گام‌به‌گام مکالمه انگلیسی از صفر — با تمرکز بر **شنیدن** و **گفتن**.

## ✨ امکانات

- **۱۰۰ درس گام‌به‌گام** — از سلام و احوال‌پرسی تا گرامر پیشرفته مکالمه‌ای
- **۱٬۵۰۰+ واژه و عبارت** با تلفظ فارسی و صدای انگلیسی بریتانیایی
- **۵۷۲ جمله دیالوگ** در ۱۰۰ مکالمه واقعی
- **۱۰ سناریوی مکالمه دوطرفه** — اپ نقش طرف مقابل را بازی می‌کند! (کافه، رستوران، تاکسی، دکتر، مصاحبه شغلی و...)
- **تمرین گفتار** با میکروفون — تشخیص صحت تلفظ با امتیاز درصدی
- **آزمون** در پایان هر درس + قفل تدریجی درس‌ها
- **۵۰۰ سؤال آزمون** کل دوره
- **ذخیره پیشرفت** و آمار کامل
- **قابل نصب روی گوشی** (PWA) و کارکرد آفلاین

## 🚀 استفاده

لینک اپ را در مرورگر گوشی باز کنید (Chrome برای بهترین عملکرد میکروفون).

نصب روی صفحه گوشی:
- **اندروید (Chrome):** منو ⋮ ← Add to Home screen
- **آیفون:** دکمه اشتراک ← Add to Home Screen

## 🛠️ اجرای محلی (نسخه توسعه)

```bash
cd english-app
python server.py
# سپس در مرورگر: http://IP-سیستم:5050
```

نسخه آنلاین از پوشه `docs/` به صورت استاتیک سرو می‌شود (GitHub Pages).

## 📁 ساختار

```
english-app/
├── docs/               ← نسخه استاتیک (GitHub Pages)
│   ├── index.html
│   ├── app.js
│   ├── styles.css
│   ├── sw.js
│   ├── manifest.json
│   ├── data/           ← ۱۰۰ درس + سناریوهای مکالمه
│   └── icons/
├── static/             ← فایل‌های نسخه توسعه (سرور Flask)
├── server.py           ← سرور توسعه محلی
└── make_icons.py       ← ساخت آیکون‌ها
```

|---|---|---|
| مبتدی | ۱-۲۰ | سلام، معرفی، اعداد، خانواده، خرید، مسیر، آب‌وهوا... |
| روزمره | ۲۱-۴۰ | دکتر، شهر، سفر، دعوت، عذرخواهی، بانک، شغل... |
